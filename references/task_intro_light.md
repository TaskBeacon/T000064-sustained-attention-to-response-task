# 持续注意反应任务：范式逻辑、神经机制与测量边界

持续注意研究需要在较短实验时程内捕捉偶发的目标维持失败，同时尽量避免把感觉辨别困难、一般运动迟缓或单次偶然错误误判为注意衰退。持续注意反应任务（Sustained Attention to Response Task, SART）以高频按键和低频抑制构成不对称的 Go/No-go 序列，使重复反应逐渐占据优势，并以稀有 No-go 试次检验参与者能否持续保持任务规则。该设计将传统警觉任务中“发现稀有信号并反应”的规则反转为“对频繁刺激反应、对稀有目标停止反应”，因而能在约数分钟内同时获得误按、漏按、反应时及其波动等指标（Robertson et al., 1997）。然而，稀有目标上的误按并非持续注意失败的专属标志；反应抑制、速度—准确权衡、动机和刺激比例均可改变同一指标。SART 的方法学价值由此建立在多指标、时序分析和适当对照之上，而非对单项错误率的构念赋值。

## 1. 范式提出与理论背景

Robertson 等（1997）最初用 SART 研究创伤性脑损伤患者及健康成人的日常动作疏失。参与者对数字流中的多数项目按键，仅在数字 3 出现时抑制反应；No-go 目标约占九分之一。原始研究发现，目标前反应加快可预测随后误按，且任务表现与日常认知失败报告及脑损伤严重度相关，据此将错误解释为受控加工向自动反应漂移的结果。后续实验进一步表明，表现取决于维持对自身行动监控的时间要求，支持 SART 对短时持续注意失败的敏感性（Manly et al., 1999）。

该范式包含相互依赖但不可互换的过程。连续 Go 试次要求维持规则、加工刺激身份并执行快速反应；稀有 No-go 试次还要求在识别目标后抑制已形成优势的运动反应。因此，No-go 误按可能源自规则表征暂时脱离、目标知觉不足、反应阈值偏低或抑制失败。事件相关电位研究进一步区分了两类外观相同的动作错误：部分错误之前已出现持续注意相关信号减弱，另一些则更符合目标出现后的抑制失败（O’Connell et al., 2009）。这一结果限定了行为指标的解释范围：误按是需要分解的终点事件，而不是单一心理过程的直接读数。

## 2. 任务逻辑、流程与核心参数

经典数字 SART 呈现 1—9，通常要求对除 3 以外的数字按键，对 3 停止反应。原始配置采用 250 ms 数字呈现和 900 ms 掩蔽，刺激起始间隔固定为 1150 ms；数字大小在五档之间变化，以降低仅凭低水平视觉特征作答的可能。高 Go 比例建立优势反应，随机或准随机数字次序使目标出现不可预测（Robertson et al., 1997）。固定节律有利于比较目标前连续反应，但也允许参与者形成时间预期，故反应时变异同时包含注意状态波动、时间估计误差和策略调整。

主要因变量包括 No-go 误按率、Go 漏按率、正确 Go 反应时的均值与变异，以及随任务时间变化的表现。误按率反映成功识别目标并维持停止规则后的综合结果；漏按更易受低唤醒、知觉遗漏或反应过慢影响；反应时标准差和变异系数刻画反应稳定性，但会受均值水平影响。目标前加速、目标前反应波动和错误后减速可用于分析状态转变与行为调整。跨视觉、听觉版本的错误、反应时和反应时变异具有较强关联，说明部分个体差异可跨感觉通道保持；两种版本的平均难度仍不同，不能直接合并常模（Seli et al., 2012）。

试次阶段决定了指标能够支持的推论。数字呈现期首先要求编码刺激身份并检索“3 时停止”的规则；掩蔽期保留反应窗口，使较晚的识别和按键仍可完成。Go 正确反应时由知觉编码、规则匹配、反应选择与运动执行共同构成，不能作为纯粹加工速度。No-go 正确拒绝没有可观测反应时，因而误按前若干 Go 试次的速度与波动常被用作注意状态的间接证据。固定刺激起始间隔便于建立连续时间序列，也使相邻试次并非统计独立；把所有试次简单平均会丢失目标前变化和任务时间效应。研究问题若关注瞬时注意疏失，宜预先规定目标前窗口或采用层级试次模型；若关注稳定个体差异，则需增加目标数并评估跨时点一致性。

任务次序和 Go 比例是关键操控。数字按顺序循环的版本使 No-go 时间可预测，更依赖节律监控；随机版本要求逐项辨认刺激。提高 Go 比例会使反应更快、误按增加，并改变参与者采用的反应策略，且该变化并非与任务无关思维简单对应（Wilson et al., 2016）。因此，研究间比较应同时报告刺激次序、No-go 比例、刺激起始间隔、反应窗口、反馈和速度—准确指导语。

## 3. 主要行为与神经科学发现

### 3.1 注意波动、思维游移与反应策略

SART 常与经验采样结合，用探针区分任务相关思维与任务无关思维。fMRI 期间的探针研究发现，报告任务无关思维前的 SART 错误较多；默认网络与执行控制区域在思维游移时可同时参与，且缺乏元觉察时的招募更强（Christoff et al., 2009）。该证据支持 SART 对注意状态波动的敏感性，但行为错误不能替代主观探针：相同误按既可能伴随思维游移，也可能来自过快的反应策略。

围绕这一问题的实验结果较为一致地显示速度—准确权衡不可忽略。统计控制错误前反应速度能够提高 SART 指标对注意疏失的解释效度（Seli et al., 2013）；改变空间不确定性或全局干扰时，误按与反应速度仍紧密耦合，支持反应策略解释（Helton et al., 2010）。要求强调准确、提供实时反馈会减慢反应并降低误按，表明误按率可被目标设定改变（Mensen et al., 2022）。直接检验“任务是否诱发无心加工”的研究也未支持将 SART 等同于必然的心智脱离状态（Dillard et al., 2014）。较稳妥的分析应联合误按、漏按、反应时分布、任务时间效应和探针报告，并在组间反应速度差异明显时预先规定权衡控制方法。

经验采样本身也会改变任务。探针要求参与者周期性检查当前意识内容，可能提高元觉察并打断原有的自动反应序列；探针前区间则混合了状态持续时间和探针预期。行为—主观对应应以同一时间窗为单位，并区分有意与无意思维游移、任务相关干扰和外部注意分散。若仅在任务结束后追问整体体验，回忆偏差会削弱对单次误按的解释。由此，带探针 SART 测量的是特定采样制度下的注意状态，不能直接等同于无探针版本的行为表现。

### 3.2 fMRI 与 EEG 证据

SART 的神经影像结果支持分布式注意与控制系统参与，而不支持以单一脑区定位“持续注意”。随机听觉提示可在总体行为变化有限时减弱右侧额—顶警觉网络的活动，提示外源提示降低了维持目标状态所需的内源控制负荷（O’Connor et al., 2011）。在发作性睡病 1 型患者中，分级 SART 的 fMRI 研究观察到扣带—岛盖和额顶活动降低，并伴随较差表现；该组间关联不能单独证明这些网络异常是症状的原因（Gool et al., 2020）。

EEG 提供了刺激识别、反应冲突与控制更新的时间信息。儿童和青少年 SART 数据显示，较高反应时变异及 ADHD 症状与较低效的任务期功能网络整合相关，但头皮信号的网络指标不等同于精确解剖定位（Machida et al., 2019）。源定位 ERP 研究在 Go 与 No-go 的 N2、P3 时段观察到额叶、岛叶和顶叶活动差异，并在肌萎缩侧索硬化患者中发现改变（McMackin et al., 2020）。这些结果说明 SART 可用于刻画感觉加工之后的运动控制和注意更新时程；临床组差异仍受运动能力、疾病负担和任务策略影响，不能由单次 ERP 或误按率作个体诊断。

## 4. 范式发展与主要应用

SART 已由脑损伤研究扩展至神经发育、老化、睡眠—觉醒障碍和神经退行性疾病。儿童 ADHD 的纵向研究发现，9—14 岁期间持续注意轨迹随症状持续或缓解而异，显示重复测量比单次组间比较更适合研究发展变化（Thomson et al., 2020）。近期带思维探针的研究进一步指出，ADHD 注意不集中症状、认知脱离症状与任务中思维游移之间的关系取决于报告来源和症状维度，尚不足以把 SART 用作诊断替代物（Wiggs et al., 2024）。

临床应用需要区分检测组间受损与评估个体变化。脑损伤、发作性睡病和神经退行性疾病均可能同时影响觉醒、视觉加工、运动执行和错误监控，因此相同误按增加可由不同功能环节产生。重复测量用于康复或疾病进展时，任务熟悉可能降低误按，症状波动又可能增加日间差异。合适的对照包括简单反应速度、独立运动测量和低抑制负荷条件；这些测量能够判断变化是否仍特异关联于持续目标维持。神经指标可补充时间或空间信息，但其增量效度应相对于行为指标单独检验。

老化研究尤其揭示策略混杂。元分析显示，老年人通常在 Go 试次更慢，却在 No-go 试次更准确；这一组合更符合年龄相关的速度—准确偏好，而非笼统的持续注意下降（Vallesi et al., 2021）。采用个体化反应窗滴定并加入金钱激励的预注册研究表明，匹配初始准确率后，年龄差异会随动机操控改变（Hanzal et al., 2025）。方法发展还包括非数字正弦光栅版本，以减少获得性脑损伤患者的数字加工要求；其与数字版本仅呈中等对应，且与自评持续注意未见稳定关联，说明平行形式需要独立效度证据（Lanssens et al., 2025）。

## 5. 测量效度与解释边界

SART 在群体研究中的优势是流程短、错误可被稳定诱发，并能同时记录准确性和连续反应动力学。原始研究及后续样本提示任务与日常认知失败存在联系，但近期疲劳人群研究发现，该联系可在员工样本出现、在学生样本缺失，说明生态效度受样本构成和自评方法调节（Schepers et al., 2023）。群体平均效应稳定也不保证个体排序可靠；少量 No-go 试次会限制误按率的分辨率，重复施测还可能带来目标熟悉和策略学习。

构念效度的主要边界来自任务不纯。误按同时依赖持续目标维持、目标识别和反应抑制；反应时变异同时受处理速度、均值水平、疲劳和时间预期影响；时间任务效应还可能反映动机变化。研究设计宜预先指定主要指标，报告速度与准确性，避免仅从 No-go 误按推断思维游移。若研究问题要求分离注意维持与抑制，应增加目标频率对照、低 Go 条件、思想探针或独立抑制任务。用于临床或个体预测时，还需在目标人群中报告重测信度、阈值稳定性和增量效度。

可靠性评估应与数据层级一致。误按率是少量二元试次的比例，内部一致性易受目标数和基率制约；反应时均值通常拥有更多有效试次，却可能掩盖短暂状态变化；标准差又依赖试次数与离群值处理。研究者应报告有效 Go/No-go 数、排除规则和反应时清理方法，并用重测相关或组内相关系数检验个体排序，不能以显著的群体均值差代替信度证据。跨版本研究还需检验测量等价性：改变刺激类别、目标比例、顺序或反馈后，即使平均表现相近，也不能假定原构念权重保持不变。

### 6.2 实现流程与关键参数

TaskBeacon 当前版本先进行 18 次练习，再完成一个连续的 225 试次正式区组。正式阶段中数字 1—9 各出现 25 次；每个数字的五档字号（48、72、94、100、120 点）各使用 5 次，试次以固定种子随机排序。数字 3 为 No-go，其他数字为 Go，正式阶段共有 25 个 No-go 与 200 个 Go 试次。任务不提供逐试次反馈，也不调整难度；练习后反馈误按率与漏按率，结束时汇总 Go 命中率、误按率、漏按率、正确 Go 平均反应时和反应时标准差。

![TaskBeacon SART 任务流程](../task_flow.png)

*图 1. TaskBeacon SART 的单试次流程。Go 条件对应数字 1、2、4—9，要求在数字或随后掩蔽阶段按空格键；No-go 条件对应数字 3，要求全程抑制按键。每个试次先呈现白色数字 250 ms，再呈现圆圈交叉掩蔽 900 ms，反应窗覆盖两阶段，总刺激起始间隔为 1150 ms。Go 期未反应记为漏按，No-go 期按键记为误按，正确抑制记为正确拒绝；按键后掩蔽仍保持至试次结束。正式任务以固定种子随机化数字与字号组合，无逐试次积分、反馈或自适应调整。*

该实现的固定节律和高 Go 比例复现了原始范式的优势反应条件。由于仅有 25 个 No-go 试次，单次误按对应 4 个百分点，个体水平分析宜同时保留逐试次数据和连续反应时指标。数字顺序经随机化，故这里的“固定”指时序和试次数固定，不应与文献中按 1—9 顺序循环的 fixed SART 混同。
