# Task Plot Brief

Title: Sustained Attention to Response Task
Construct: sustained attention / response inhibition

- Go row: digit 1, 2, or 4-9 for 250 ms; press Space during digit or mask; encircled-X mask for 900 ms.
- No-go row: digit 3 for 250 ms; withhold throughout digit and mask; same 900 ms encircled-X mask.
- Practice: 18 trials followed by a summary. Scored: one continuous 225-trial block.
